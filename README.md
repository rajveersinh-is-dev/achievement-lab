Scratch repo used to trigger GitHub profile achievements (Quickdraw, YOLO, Pull Shark). Safe to delete.

## Features

- Clean, modern Python 3.10+ implementation.
- Typed signatures and robust error handling.
- Comprehensive unit test coverage.

## Installation & Usage

```bash
git clone https://github.com/rajveersinh-is-dev/achievement-lab.git
cd achievement-lab
python "main.py" --help
```

## Testing

```bash
pytest tests/
```
